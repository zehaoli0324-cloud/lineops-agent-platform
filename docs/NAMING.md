# 命名建议

LineOps 中 Line 指 production line，即产线；Ops 指 operations，即运行与运维。这是当前项目的工作名称，覆盖直接，但不突出自主异常处置。

| 候选 | 中文建议 | 定位 |
| --- | --- | --- |
| PlantSentinel | 厂巡 | 推荐用于完整平台，强调工厂设备感知、巡检和处置 |
| MaintPilot | 维航 | 强调维护任务辅助、规划与执行 |
| ForgeOps | 工铸 | 更偏工业系统与工程平台的品牌风格 |
| Night Shift Agent | 夜班值守 Agent | 推荐比赛副标题，直接说明无人值守工作 |

建议完整项目展示名为“厂巡 PlantSentinel”，比赛展示名为“厂巡夜班 Night Shift Agent”。这里只提供候选，不声称名称唯一或可注册；未擅自重命名已有仓库。
