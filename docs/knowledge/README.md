## 使用约定

- 外部事实尽量引用论文、作者代码、学校或厂商官方资料；文中 `[LAB-xx]`、`[IND-xx]` 对应来源目录。
- 每条研究笔记区分“来源内容”和“LineOps 建议”。论文成功不自动构成我们的能力证据。
- 标明公开材料的证据类型：论文、开源实现、机构报道、产品说明或合作公告。厂商陈述不当作独立验收。
- 已有十个固定用例是功能回归；未完成的任务、模型实验和恢复机制明确标为拟议。
- 新资料补充发布日期、检索日期和阅读深度；无法访问全文时写明，不能标作全文复现。
- 新运行结果记录提交版本、配置、任务、原始轨迹和失败案例，再更新 [STATUS](../STATUS.md)。
- 知识库只保存摘要与链接，不复制论文全文，不提交密钥、客户数据或未经授权的材料。
